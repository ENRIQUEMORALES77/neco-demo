¿A qué dirección apunta el QR?

El QR tiene que llevar a una web publicada para que el gerente lo abra con su móvil. Por defecto es el dominio de config.js. Si aún no está comprado, pon aquí la dirección de GitHub Pages (por ejemplo https://usuario.github.io/neco-demo/).
